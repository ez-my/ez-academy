# Trial access reactivation — local handoff (26 October 2026, MYT)

## Outcome and authorization basis

Locally restored **51 SPM Reading tests and 40 SPM Listening tests** for the existing app routes. This is not a production deployment. Registration/authentication, plan/practice allowances, completed-part locks, history and draft handling remain in place; “public app access” does not mean anonymous access or unlimited practice.

The authorization basis is **the user's attestation**, supplied in this task: “ya, sudah diluluskan tanpa perlu mengubah fail asal”, with explicit instruction that use/redistribution of the current inventory is approved. No independent legal-document or rights-holder review is claimed. No new grant document was found, fabricated or substituted for that attestation. The prior hold report and inventory remain historical evidence, not the current access decision.

`src/lib/trialPaperAuthorization.json` is the exact current allowlist: separate Reading/Listening IDs plus their question, answer (when present), and audio (when present) source IDs. It also pins all 66 repository original-file hashes. The existing per-set page/asset lists remain in `AFFECTED_ASSETS.md` and `inventory.json`; those evidence files were not rewritten. Permission is not inferred for future years, state-name prefixes, replacement source IDs or unlisted assets.

## Narrow implementation

- `src/lib/trialPaperRights.ts`: compare each requested family against the static source-ID tuple. Unknown IDs, future additions, cross-skill-only IDs and changed question/key/audio references fail closed. No request parameter or environment flag grants rights.
- `src/pages/ReadEZ.tsx`, `src/pages/ListenEZ.tsx`: restore real libraries through React lazy imports and accessible Suspense loading states instead of globally substituting the hold notice.
- `src/components/TrialReadingLibrary.tsx`, `TrialListeningLibrary.tsx`: filter catalogue entries through family authorization and guard selected workspaces. Original downloads, previews, figures, zoom and audio links are restored for authorized entries.
- `src/lib/authorizedReadingPaperLoaders.ts`: 51 explicit lazy JSON imports replace the wildcard import. Dropping a future JSON in the directory does not automatically publish it.
- `src/server/trialPaperBuildGuard.ts`, `vite.config.ts`: before Vite publishes shared catalogue/OCR/key modules, reject unauthorized catalogue/source-ID drift or changes to the 66 pinned original files. This intentionally requires a new explicit authorization/integrity review for future source changes. An unrelated future JSON is not imported automatically.
- `src/server/listeningAudio.ts`, `netlify/functions/listening-audio.ts`: existing transport/range protections retained; authorization is now explicitly Listening-scoped. Approved recordings use the production allowlist default; denied recordings stop before Drive access.
- `src/server/practiceRoutes.ts`: check Reading/Listening-specific authorization before history/database reads, grading or usage writes. Existing practice budgets, rewards, locks, authentication and atomic saves are unchanged.
- `src/server/listeningResults.ts`: also guard the legacy/dev listening check handler before grading/save. In the app, practice routes are registered first and remain the budget/lock-enforcing path.
- `src/components/TrialPaperRightsNotice.tsx`: retain the notice for unauthorized assets, remove misleading whole-library replacement exports.
- `src/lib/trialPaperText.ts` and Listening library: marked OCR text bypasses legacy text-layout helpers that strip SULIT/TERHAD. The original marked text is rendered intact in readable view. Existing data/layout files were not edited. Unmarked content keeps existing organized question UI; the separate answer sheet remains usable for marked parts.
- Tests updated in `tests/paper-rights.test.ts`, `tests/practice-routes.test.ts`, `tests/full-migration.test.ts` (malformed range for an authorized recording is now correctly 416 rather than the old blanket 451).
- `netlify/functions/api.mjs` was regenerated by the existing build. Other pre-existing generated/source changes were not restored or committed.
